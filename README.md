# Fileloom

Fileloom is a file browser and reader for documents, ebooks, comics and everyday files.
The iPhone and iPad version is being prepared for its first App Store release.

## Help and support

Email **beefiker@gmail.com** for help. Please include your Fileloom version,
iPhone or iPad model, iOS version, file type and the steps that led to the problem.
Do not send passwords, access tokens or private documents. If a sample file is
needed, use a non-sensitive file you have permission to share.

- [Privacy policy for iPhone and iPad](PRIVACY.md)
- [Third-party release materials](https://github.com/beefiker/fileloom-release-materials/releases)
- [Android version on Google Play](https://play.google.com/store/apps/details?id=io.fileloom.app)

## Release materials

This repository hosts reviewed third-party library sources and the compiled
materials needed to relink matching Fileloom iOS releases with modified libraries.
Fileloom application source code is private and is not published here.

Use materials matching the exact app version and build. Read the instructions and
verify the published checksums before using a release package. An empty Releases
page means no package has been published yet; it is not a download error.
